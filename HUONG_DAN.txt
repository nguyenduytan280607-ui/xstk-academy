CẬP NHẬT TRÊN GITHUB (nếu main.jsx và styles.css trên GitHub vẫn là bản Flashcard 3.0):
1. Sao lưu main.jsx và styles.css từ GitHub.
2. Thay main.jsx, styles.css bằng bản trong ZIP.
3. Thêm XSTKCalculator.jsx vào thư mục gốc, cùng cấp main.jsx.
4. Nếu GitHub chưa có FlashcardNotebook.jsx thì bổ sung file đi kèm.
5. Giữ nguyên data.js, server.js, firebase.js, package.json, ảnh và PDF.
6. Commit lên main và kiểm tra Vercel Build Logs.
7. Mở menu 'Máy tính XSTK' và thử 4 chế độ.

Nếu mã trên GitHub đã thay đổi sau bản Flashcard 3.0: KHÔNG ghi đè main.jsx/styles.css. Gửi hai file mới nhất để ghép riêng.
