XSTK ACADEMY — SỬA LỖI THI KẾT HỢP 2.1

NGUYÊN NHÂN: Backend chỉ cho count = 5, 10, 20. Frontend gửi count=2 cho câu tự luận nên API trả HTTP 400.

THAY ĐỔI:
- Cho phép số câu nguyên từ 1 đến 20 cho mỗi yêu cầu tạo đề.
- Hỗ trợ alias type=mcq (chuẩn hóa thành multiple).
- Giữ nguyên endpoints /api/solve, /api/grade, /api/practice/generate, logic CORS, các API key và xử lý ảnh.

CẬP NHẬT:
1. Mở GitHub repo nguyenduytan280607-ui/xstk-academy, chọn file server.js.
2. Bấm biểu tượng bút chì Edit, thay toàn bộ nội dung bằng file server.js mới, Commit changes trên nhánh main. Có thể dùng Add file > Upload files và thay file server.js cùng tên.
3. Vào Render > dịch vụ backend > Events/Logs, kiểm tra triển khai từ commit mới. Nếu không tự động triển khai, dùng Manual Deploy > Deploy latest commit.
4. Mở https://xstk-academy.onrender.com/health để kiểm tra API sống.
5. Mở domain Vercel production https://xstk-academy-nu.vercel.app, thử Thi kết hợp: 5 câu trắc nghiệm + 2 câu tự luận.

LƯU Ý:
- Chỉ cập nhật server.js; KHÔNG sửa data.js, main.jsx, styles.css, package.json hoặc biến môi trường.
- Sửa lỗi HTTP 400 về số câu. Không bảo đảm AI tạo đủ câu / chấm thành công nếu dịch vụ Groq gặp lỗi.
- Domain Preview Vercel có thể vẫn bị CORS nếu chưa thêm vào FRONTEND_URL; production đang được cho phép.
- Lỗi trang trắng React là vấn đề riêng, cần Console để xác định.
